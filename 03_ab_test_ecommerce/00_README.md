# A/B Test Analysis: E-commerce Conversion

## Описание проекта

Учебный проект по анализу результатов A/B-теста для e-commerce сайта.  
Компания разработала новую веб-страницу и хочет понять, изменилась ли конверсия пользователей по сравнению со старой страницей.

В проекте проверяется влияние новой страницы на бинарную метрику конверсии:

- `converted = 1` — пользователь сконвертировался;
- `converted = 0` — пользователь не сконвертировался.

Основная задача — определить, есть ли статистически значимое различие между конверсией старой и новой страницы.

## Источник данных

Ecommerce A/B Testing Dataset

Файл данных:

- `ab_test.csv`

## Цель анализа

Проверить, изменилась ли conversion rate после показа новой страницы.

## Гипотезы

В проекте используется двусторонняя проверка гипотез:

- H0: `CR_new = CR_old`  
  Конверсия новой страницы не отличается от конверсии старой страницы.

- H1: `CR_new ≠ CR_old`  
  Конверсия новой страницы статистически отличается от конверсии старой страницы.
