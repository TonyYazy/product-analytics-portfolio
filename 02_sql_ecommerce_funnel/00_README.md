# SQL E-commerce Funnel Analysis

## Goal
Analyze user behavior in an e-commerce funnel and identify conversion bottlenecks.

## Dataset
Kaggle e-commerce event dataset.

## Tools
PostgreSQL, PGAdmin, SQL, VS Code.

## Analysis
- Sales funnel: page_view → add_to_cart → checkout_start → payment_info → purchase
- Funnel by traffic source
- Time-to-conversion
- Revenue metrics: AOV, ARPU, ARPPU

## Files
- `funnel_analysis.sql` — SQL queries
- `schema.sql` — table structure
- `insights.md` — business insights and recommendations
