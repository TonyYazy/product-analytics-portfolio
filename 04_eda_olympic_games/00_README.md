# Pandas EDA Practice: Olympic Games Dataset

## Описание проекта

Учебный проект по разведочному анализу данных и практике работы с библиотекой Pandas.  
В ноутбуке используются открытые датасеты с данными об олимпийских спортсменах, результатах соревнований и странах/NOC-кодах.

Проект показывает базовые и продвинутые операции анализа данных в Python: загрузку данных, фильтрацию, создание новых признаков, объединение таблиц, обработку пропусков, агрегации, pivot-таблицы и работу с временными признаками.

## Цель проекта

Закрепить навыки работы с Pandas на реальных табличных данных и показать базовый EDA-пайплайн для анализа спортивных/исторических данных.

## Используемые данные

Данные загружаются напрямую из открытого GitHub-репозитория:

- `bios.csv` — данные об олимпийских спортсменах;
- `results.csv` — результаты соревнований;
- `noc_regions.csv` — справочник стран и NOC-кодов;
- `coffee.csv` — небольшой тренировочный датасет для практики Pandas-операций.

Источник данных:  
https://github.com/KeithGalli/complete-pandas-tutorial

## Инструменты

- Python
- Pandas
- NumPy
- Jupyter Notebook

## Что сделано

- Загрузка данных из публичных CSV-файлов;
- Первичный просмотр данных через `head()`, `tail()`, `describe()`;
- Фильтрация строк по условиям;
- Работа со строковыми признаками;
- Создание новых колонок;
- Преобразование дат;
- Категоризация спортсменов по росту и весу;
- Объединение таблиц через `merge`;
- Объединение датафреймов через `concat`;
- Обработка пропусков через `fillna`, `interpolate`, `dropna`;
- Группировки и агрегации через `groupby`;
- Построение pivot-таблиц;
- Расчет накопительных значений;
- Использование `shift`, `rank`, `rolling`.
